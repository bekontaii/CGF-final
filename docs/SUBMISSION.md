# Submission preparation

The project can be built and demonstrated locally. Before uploading the final coursework, complete the fields that only the team or instructor can supply.

1. Enter the actual team name, group, members and module ownership in `assets/team.json`.
2. Confirm the assigned topic number and exact title. Copy its Section 6 checklist into the report and evaluate every required technique against the running build.
3. Replace the team fields in `WeatherWorld_Report.docx` and `WeatherWorld_Defence.pptx` with the same information. Regenerate the PDF after editing the report.
4. Build from the source archive on the Windows 10 lab PC. Run the tests and measure the default 1280×720 scene with shadows on and off. Local Mac measurements are identified separately in the report.
5. Watch `WeatherWorld-demo.mp4`. Upload it to YouTube or Google Drive, allow access by link and paste the verified URL into the report and `backup_video_url` field.
6. Rehearse the five minute presentation and live demonstration. Every member should be able to change the shadow shader and explain the resulting image.
7. Submit source, README, report and the 60–120 second backup video. The supplied course document states a deadline of 14 November 2026 and a 10% penalty for each late day.

Substantial generated code and documentation assistance is disclosed in the report. Keep the disclosure and all upstream library/font licenses in the submitted package.
