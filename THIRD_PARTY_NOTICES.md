## Weather data

Live weather is provided by Open-Meteo: <https://open-meteo.com/>. Its weather data is licensed under Creative Commons Attribution 4.0 (CC BY 4.0): <https://creativecommons.org/licenses/by/4.0/>. Attribution in the application and report must be preserved. The public free service is intended for non-commercial usage and is subject to Open-Meteo terms and request limits: <https://open-meteo.com/en/terms>.

“Live” refers to the provider's current model-based weather values, not a sensor directly connected to the application. The API response timestamp is shown. Simulation presets are synthetic and are labelled separately.

## References for graphics concepts

The graphics implementation uses standard concepts: perspective and view matrices, Blinn-Phong lighting, depth shadow mapping and percentage-closer filtering. API behavior can be checked against the Khronos OpenGL reference pages: <https://registry.khronos.org/OpenGL-Refpages/gl4/>. All project shader files are included for inspection and explanation at the defence.
